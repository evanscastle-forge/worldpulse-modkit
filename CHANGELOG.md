# Changelog

All notable changes to the WorldPulse modkit. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versions: [SemVer](https://semver.org/). `VERSION` holds the modkit's version; the game version and
mod API it matches are in `game.json`.

## Unreleased

- The repo is now `modkit-worldpulse` on GitHub (was `worldpulse-modkit`; the old URL redirects): the clone line in `README.md` and the bundles uses the new name.
- `VERSION`, this changelog, and maintainer skills in `.claude/skills/` (`sync-from-game`, `release`).

## 0.1.0 - 2026-10-21

First recorded version.

- Docs, agent instructions (`AGENTS.md`), workflows, role cards, prompts and `tools/modkit.py`.
- Three example mods: furhats, tundrawolves, flax.
- The reference panel adapter, toolkit tests and CI (Linux, Windows, macOS).
- The chat loop: `save-reply`, `tests/expect.json` checks, a bigger small bundle.
- Doc fixes from the dogfood runs.
- README: clone from `github.com/evanscastle-forge/worldpulse-modkit`.
