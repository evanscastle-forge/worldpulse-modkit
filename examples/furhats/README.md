# Fur Hats

Adds a **fur hat**: leather and fur with ear flaps, made at the tailor bench from 20 leather.
Warmer than a tuque (comfortable 10° colder), a little protection (armor 5), too hot for summer.
Set a bill for it at the tailor bench; colonists wear it when the days turn cold.

- Adds: `furhats.item.fur_hat`, with its own map, ground and ID-card sprites
- Overrides: none
- Made for WorldPulse mod API 1
