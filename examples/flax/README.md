# Flax and Linen

Adds **flax**, a fibre crop that grows in cooler weather than cotton (from 2°C), and **linen**, its
fibre, which the tailor bench makes into a **linen shirt**: a light top that keeps colonists
comfortable in the heat (heat +6).

- Adds: `flax.plant.flax` (in the grow-zone menu), `flax.item.linen`, `flax.item.linen_shirt`
- Overrides: none
- Made for WorldPulse mod API 1
