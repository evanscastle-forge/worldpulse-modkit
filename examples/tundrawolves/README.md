# Tundra Wolves

Adds the **arctic wolf** to the tundra: a pale, smaller wolf (60 health, bites for 8) that hunts
hares and elk and only rarely turns on colonists. Hunt them for meat and 18 leather each.

- Adds: `tundrawolves.animal.arctic_wolf`
- Overrides: `core.biome.tundra` (to add the wolf to its animals); conflicts with other mods that change the tundra
- Made for WorldPulse mod API 1. New tundra maps get wolves at once; maps you already know get them as they wander in.
